# Jetski Rush
## What does randomization do to this game?
Access to each of Jetski Rush's 12 tracks is shuffled into the item pool; you start with one randomly chosen track, and the rest must be found in the multiworld.
## What is the goal of this game in Archipelago?
In Jetski Rush, the goal is to complete a configurable number of tracks. By default, this number is set to 8.
## Does this work outside of Time Trials (single player)?
It might, but this has not been tested, and you may encounter issues - sticking to a single-player, private instance of the game is recommended.
